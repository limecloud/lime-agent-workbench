# Lime Agent Workbench

Lime Agent Workbench 是 Lime 的 AgentRuntime 与 AgentUI 标准入口。它参考 AG-UI 的文档组织方式，但内容以 Lime 当前实现为事实源：App Server、RuntimeCore、ExecutionBackend、共享 AgentUI 投影、evidence/replay/review 与治理分类。

## 本地开发

```bash
npm install
npm run docs:dev
```

## 构建

```bash
npm run docs:build
```

GitHub Pages 构建产物位于 `docs/.vitepress/dist`。
